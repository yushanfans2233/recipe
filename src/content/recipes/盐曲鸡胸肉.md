## 食材
| 食材 | 克重(g) |
| ---- | ---- |
| 米曲 | 200 |
| 食用盐 | 53 |
| 纯净水/矿泉水 | 300 |

## 制作
| 步骤 | 时间 |
| ---- | ---- |
| [调配混合](#调配混合) | 即时 |
| [发酵养护](#发酵养护) | 6~14天（常温阴凉处） |
| [成品储存](#成品储存) | 发酵完成后长期冷藏 |
| 盐曲腌肉用法 | 单次腌制30min~2h |

### 调配混合
1. 准备干净无油无水的750ml密封罐
2. 罐内放入200g米曲、53g食用盐
3. 倒入300g纯净水/矿泉水
4. 取干净无油无水筷子充分搅拌均匀
5. 盖上盖子密封

### 发酵养护
1. 放置阴凉干燥避光处保存
2. 每日开盖一次，用干净无油无水筷子搅拌一次
3. 初期会有淡淡馊味，米粒完整；持续搅拌后米粒逐步碎裂，最终呈稀粥糊状
4. 发酵成熟标准：入口先咸，后鲜带微甜，无酸臭、苦味、腐坏味
5. 发酵时长：常温6~8天；气温偏低需14天
6. 发酵合格判定：无发霉，仅淡发酵鲜甜味；若长毛、发苦、发臭整罐丢弃不可食用

### 成品储存
1. 发酵完成后移入冰箱保鲜层
2. 冷藏可存放3~4个月

### 盐曲腌肉用法（以鸡胸肉为例）
1. 处理鸡胸肉：剔除油脂、筋膜杂质，从厚处切片
2. 盐曲用量：肉总重量的10%（例：200g鸡胸肉配20g自制盐曲）
3. 自制低盐盐曲可酌情多加；市售高咸盐曲严格控制10%用量
4. 肉与盐曲充分抓匀，每片肉均匀裹上腌料
5. 覆保鲜膜，常温腌制30分钟~2小时
6. 腌好的肉可煎、蒸、煮，无需葱姜蒜及额外调味
