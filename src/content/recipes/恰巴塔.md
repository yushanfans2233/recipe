## 食材
| 食材   | 克重(g) |
| ---- | ----- |
| 高筋面粉 | 100   |
| 干酵母  | 0.6   |
| 盐    | 1.6   |
| 水    | 80~90 |
| 橄榄油  | 8     |
## 制作

| 步骤      | 时间           |
| ------- | ------------ |
| [和面](#和面) | DAY1 晚 2h    |
| [烘焙](#烘焙) | DAY2 早 10min |

### 和面
1. 将除面粉外所有食材混和均匀
2. 加入面粉混和均匀
3. 放入冰箱
4. 30min折叠
5. 30min折叠
6. 30min折叠
### 烘焙
1. 面团表面,案板撒干粉
2. 将装面包的容器倒扣
3. 表面再撒干粉并整理成长方形
4. 分成两个
5. 翻转移入煎锅松弛20min
6. 中大火烙
7. 表面金黄就熟了
