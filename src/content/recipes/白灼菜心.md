## 食材清单

### 主食材

| 食材  | 数量      |
| --- | ------- |
| 菜心  | 500g    |
| 大蒜  | 20g（4瓣） |
| 洋葱  | 20g     |
| 大葱  | 10g     |

### 调味

料汁

| 食材  | 数量        |
| --- | --------- |
| 生抽  | 4勺（约40g）  |
| 白糖  | 1~2勺（约7g） |
| 鸡精  | 1勺        |
| 蚝油  | 半勺        |
| 清水  | 3勺（另备）    |

| 食用油      | 适量        |
| -------- | --------- |

## 制作流程

|步骤|时间|
|---|---|
|[备菜](#备菜)|10min|
|[焯烫菜心](#焯烫菜心)|2min|
|[熬制白灼汁&装盘](#熬制白灼汁装盘)|5min|

### 备菜

1. **处理菜心**：
	1. 摘除菜心老叶，保留嫩叶；
	2. 用指甲掐试茎部，掐不动则用削皮刀削去外皮，清理干净后洗净备用。

2. **制备小料**：
	1. 大蒜切蒜末，洋葱切细丁
	2. 大葱取外层4层外皮斜切葱丝，红辣椒去籽切丝备用。

3. **调配基础料汁**：
	1. 混合料汁
	2. 单独备好3勺清水备用。

### 焯烫菜心

1. 锅中加半锅清水，放入1勺盐、1勺食用油，可加入半勺高度白酒。

2. 大火将水烧开，码齐菜心梗先下锅烫十几秒，再将整根菜心全部下入锅中。

3. 全程焯烫1分钟，到点后无需等水沸腾，立即关火捞出菜心，过凉水降温，控干水分后整齐码入盘中。

### 熬制白灼汁&装盘

1. 热锅凉油，下入蒜末、洋葱末，开中小火慢炒。

2. 炒至20%蒜末呈金黄色时，立刻转最小火，避免小料炒苦。

3. 保持最小火，倒入提前调好的料汁搅拌至冒泡，加入备好的3勺清水。

4. 调大火将汤汁煮沸，即刻关火，将熬好的白灼汁均匀淋在菜心上即可。

## TIPS

1. 白灼汁加少量洋葱丁，比单纯用蒜末更香，是提升风味的关键技巧。

2. 焯菜加盐可让菜心色泽翠绿，加食用油能提亮颜色，少许白酒可增脆锁鲜。

3. 菜心焯烫严格控制1分钟，超时容易软烂，过凉水是保持脆嫩口感的核心步骤。

4. 炒蒜料一定要把控火候，蒜末少量金黄即刻转小火，炒苦会毁掉整道菜品味道。

5. 不喜甜食可将白糖减量至1勺，适配清淡口味。
