## 食材
以4个鸡蛋为例
一个鸡蛋50g 盐0.8g

| 食材        | 克重(g) |
| --------- | ----- |
| 鸡蛋        | 100   |
| 温水(40℃左右) | 180   |
| 盐         | 1.6   |

| 调味   | 量   |
| ---- | --- |
| 葱花   | 少许  |
| 香油   | 半勺  |
| 薄盐生抽 | 2勺  |

## 制作
| 步骤 | 用时 |
| --------- | ------------- |
| [调兑蛋液](#调兑蛋液) | 数分钟 |
| [蛋液处理](#蛋液处理) | 数分钟 |
| [蒸制](#蒸制) | 8-14分钟 |

### 调兑蛋液
1. 鸡蛋打入盆中，加入40℃左右温水、食盐，斜放容器搅拌至融合，产生泡沫属正常现象
2. 蛋水比例1:1.8，单枚鸡蛋加盐0.8克，4枚鸡蛋合计加盐约3克

### 蛋液处理
1. 选用盘子、小碗等容器，金属容器熟制更快，深容器成熟偏慢
2. 蛋液倒入容器后过滤

### 蒸制
1. 蒸锅加水放盖帘，冷水放入蛋液，锅盖留一道小缝
2. 大火烧至水开上汽，立刻转最小火蒸制
3. 4个及以下鸡蛋蒸8分钟、4个以上蒸13分钟可开盖查看，晃动后表面凝固即熟透；4个鸡蛋全程约蒸14分钟
