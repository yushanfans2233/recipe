## 食材
**主食材**

| 食材  | 数量   |
| --- | ---- |
| 包菜  | 500g |
| 干香菇 | 6~7个 |
**调味**

| 食材  | 数量   |
| --- | ---- |
| 盐   | 1~2g |
| 糖   | 1~2g |
| 蒜   | 2~3瓣 |
| 猪油  | 10g  |

## 制作

| 步骤      | 时间    |
| ------- | ----- |
| [备菜](#备菜) | 2h    |
| 烘焙 | 10min |

### 备菜
1. **泡发**香菇切条
2. 蒜切片
3. 香菇切条
### 炒
1. 热锅凉猪油润锅
2. 转最小火放入蒜片香菇
3. 炸到蒜片有点微微泛黄
4. 转中火，加入包菜丝
5. 炒的菜的体量缩小之后，有点塌架的感觉
6. 放入盐,糖
7. 炒化调味出锅
