## 食材
**主食材**

| 食材  | 数量   |
| --- | ---- |
| 包菜  | 500g |
| 干香菇 | 6~7个 |
**调味**

| 食材  | 数量   |
| --- | ---- |
| 盐   | 1~2g |
| 糖   | 1~2g |
| 蒜   | 2~3瓣 |
| 猪油  | 10g  |

## 制作

| 步骤      | 时间    |
| ------- | ----- |
| [备菜](#备菜) | 2h    |
| [炒](#炒)  | 10min |

### 备菜
1. 调味盘
	1. 葱姜蒜
	2. 豆瓣酱
2. 切丝
	1. 胡萝卜
	2. 青椒
	3. 木耳
	4. 里脊肉
3. 腌肉
	1. 生抽
	2. 料酒
	3. 淀粉
4. 酱汁
	1. 两勺生抽
	2. 半勺老抽
	3. 一勺蚝油
	4. 一勺陈醋
	5. 一勺白糖
	6. 一勺淀粉
	7. 半碗清水
### 炒
1. 肉丝炒至变色出锅
2. 锅中加入调料盘中调味
3. 再加入配菜炒软
4. 最后加入肉丝翻炒均匀，淋上酱汁
5. 翻炒至酱汁浓稠出锅
