## 食材
**主食材**

| 食材  | 数量   |
| --- | ---- |
| 包菜  | 300g |
| 西红柿 | 2个   |
| 尖椒  | 1根   |
**调味**

| 食材  | 数量   |
| --- | ---- |
| 盐   | 1~2g |
| 糖   | 1~2g |
| 蒜   | 2~3瓣 |
| 猪油  | 10g  |

## 制作

| 步骤      | 时间    |
| ------- | ----- |
| [备菜](#备菜) | 15min |
| [烹饪](#烹饪) | 10min |
 
### 备菜
1. 蒜切片,青椒切丝 
2. 包菜切丝
3. 西红柿切块
### 烹饪
1. 热锅凉猪油润锅
2. 转最中火放入蒜片炸香
3. 炒的菜的体量缩小之后，有点塌架的感觉  
4. 放入盐,糖
5. 炒化调味盛出备用
6. 不用刷锅，加一点点油放西红柿
7. 加盐,糖炒出沙
8. 混合包菜，加入蒜片、青椒丝，炒融合出锅
