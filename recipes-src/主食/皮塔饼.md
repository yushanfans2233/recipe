## 食材

可以做6张饼

| 食材    | 克重(g) |
| ----- | ----- |
| 中筋面粉  | 360   |
| 盐     | 4     |
| 温水35℃ | 250   |
| 酵母    | 3     |
| 橄榄油   | 12    |

## 制作
| 步骤        | 用时            |
| --------- | ------------- |
| [[#和面醒发]] | 40分钟起（冬季约1小时） |
| [[#分团松弛]] | 35分钟          |
| [[#烙制]]   | 数分钟           |

### 和面醒发
1. 温水化开酵母，加面粉揉至无干粉，醒面20分钟
2. 放入橄榄油，揉6-7分钟至光滑，再次醒发

### 分团松弛
1. 面团排气，分成6份，滚圆后擀开
2. 盖保鲜膜松弛5分钟，再次擀开
3. 加盖醒发30分钟

### 烙制
1. 锅烧热转小火，放入面饼，定型后转动均匀受热
2. 多次翻面，避免饼皮开裂
3. 翻面2-3次至饼鼓起，熟透即可，可加鸡蛋
