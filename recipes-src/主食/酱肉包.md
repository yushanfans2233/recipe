## 食材

共10个大包子（每个约50g面粉）

### 面皮食材
| 食材   | 克重(g) |
| ---- | ----- |
| 中筋面粉 | 500   |
| 酵母   | 5     |
| 冰水   | 270   |
| 橄榄油  | 20g   |

### 肉馅食材
| 食材      | 克重(g) |
| ------- | ----- |
| 猪肉（纯瘦肉） | 500   |
| 姜粉      | 2g    |
| 葱粉      | 2g    |

炒制调味
- [ ] 生抽 30g
- [ ] 甜面酱 40g
- [ ] 老抽 15g
- [ ] 蚝油 20g
- [ ] 十三香 2g

- [ ] 食用盐 3g
- [ ] 大葱 30g
- [ ] 鸡精 3g
- [ ] 香油 10g

## 制作
| 步骤        | 用时           |
| --------- | ------------ |
| [[#制作肉馅]] | 20分钟         |
| [[#和面]]   | 1-1.5小时（看温度） |
| [[#蒸制]]   | 18分钟         |

### 制作肉馅
1. 肉绞成有大颗粒的肉馅, 加入葱姜粉,搅拌均匀
2. 锅里放少量食用油，中小火烧热,倒入1/3肉馅，煸至没有血色
3. 加入炒制调味,煸炒出酱香
4. 晾凉后与之前2/3馅料混合
5. 冰箱冷冻保存

### 和面
1. 混和面皮材料至无干粉
2. 静置10分钟后揉至光滑

### 包与蒸制
1. 分面剂子 <=80g每个
2. 擀成中间厚边缘薄的圆皮，包入肉馅捏褶
3. 醒发20~30分钟
4. 8个冷冻
5. 2个冷水上锅，大火烧开后转中大火蒸15分钟
6. 关火焖3分钟再开盖，避免塌陷
