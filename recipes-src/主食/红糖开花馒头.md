## 食材
### 波兰种
| 食材 | 克重(g) |
| ---- | ---- |
| 面粉 | 150 |
| 清水 | 150 |
| 耐高糖酵母粉 | 1.5 |

### 主面团
| 食材  | 克重(g) |
| --- | ----- |
| 红糖  | 80    |
| 开水  | 110   |
| 面粉  | 350   |
| 波兰种 |       |
| 大枣碎 | 150   |

| 步骤 | 用时 |
| --------- | ------------- |

### 制作波兰种
1. 将150g面粉、150g清水、1.5g耐高糖酵母粉混合，搅拌成稀糊状。
2. 容器侧面做好标记，放入冰箱冷藏醒发，至体积变为原来2-3倍，常规冷藏时长约8小时，可根据冰箱温度灵活调整。
3. 小贴士：红糖用量高，必须使用耐高糖酵母粉，避免面团发酵失败。

### 揉制主面团
1. 80g红糖加入110g开水搅拌化开，放置至常温。
2. 盆中放入350g面粉、150g醒发好的波兰种，倒入放凉的红糖水，搅拌成絮状。
3. 下手揉面，全程揉制5分钟，将面团揉匀揉细。
4. 小贴士：红糖面团需减少用水量，面粉吸水性不同，可酌情调整水量。

### 添加大枣碎并整形
1. 把面团摊平，放入大枣碎，折叠面团反复揉制，直至枣碎分布均匀。大枣碎用量可按个人喜好增减。
2. 将面团搓成长条，搓制不均可借助菜板滚动整理。
3. 按三根手指宽度做标记，用拇指和食指掐下面剂，该做法能提升开花概率。
4. 整理面剂底部使其平整，摆放到蒸屉纸上，面剂之间预留一根手指的间距。

### 二次醒发
1. 将摆好的面剂放在温水锅上进行醒发。
2. 醒发40分钟，待面剂间距缩至约半个手指宽度，即可开始蒸制。

### 蒸制
1. 蒸锅内加足量清水，全程开大火蒸制，防止烧干锅。
2. 水开后开始计时，持续蒸15分钟即可出锅。
3. 小贴士：制作红糖开花馒头无需添加碱面。
